# momomath-year2 — project rules

## STANDING RULES (user-mandated, never drop without explicit user approval)

### R1 — PLAN.md checklist is mandatory
- There must ALWAYS be a `PLAN.md` in the repo root with a live checklist
  (`- [ ]` open / `- [x]` done) that reflects the current work.
- At the start of EVERY session, re-read `PLAN.md` before editing code, and
  keep the checklist in sync: tick a box only when the work is actually done
  and its gate has passed.
- If a task has no `PLAN.md` yet, create one with a checklist BEFORE coding.

### R2 — Work the plan through, do not stop early
- Do not stop until every open checklist item in `PLAN.md` is done, unless
  the user explicitly says to pause.
- Work items in order; run each item's gate (see `PLAN.md` §13.7 for the
  battle gates: `npx tsc -b` → full `npx vitest run` → `npm run verify`).

### R3 — RULE R0: the battle feature is purely additive
(See `PLAN.md` §13.0 for the full statement.) Battles may only ADD. No edits
to existing mechanics or numbers (lessons/crowns, XP & gems, `STAR_THRESHOLDS`,
chest odds/pity, shop, leagues, quests, achievement feeds, arcade, library,
cloud-sync behavior). Existing tests must stay green with NO edits. New
coverage goes in new `tests/battle/*.test.ts`. Save migration is a single
additive `v11 → v12` step that only backfills battle defaults.

### R4 — RULE: premium voices are mandatory (never regress to device speech)
- Every spoken string routes through the premium Fish Audio voice layer:
  `src/engine/ttsPremium.ts` computes a clip key → the pre-generated mp3 in
  `public/tts/<key>.mp3` is played; on ANY miss it falls back to the device
  Web Speech path in `src/engine/tts.ts`. Device Web Speech is a FALLBACK
  ONLY, never the primary voice.
- The premium cast (user-picked 2026-10-17), one character voice per language,
  lives in `PREMIUM_VOICES` (ttsPremium.ts): EN(`en-GB`)=Sonic, AR(`ar-EG`)=
  movie Tails, DE(`de-DE`)=movie Knuckles. To change a voice, swap its Fish
  `reference_id` in `PREMIUM_VOICES` and regenerate that locale's clips.
- Clips are build-time only, generated by `scripts/generate-tts.mts` (Fish
  model `s2.1-pro-free`, key read from `FISH_AUDIO_API_KEY` in `.env.local` —
  never logged, never committed). `public/tts/manifest.json` lists every key.
- DEPLOY HYGIENE: `public/tts/` (5,984 clips, ~145MB) + `ttsPremium.ts` carry
  the voices. Never deploy a tree that lacks them — that DROPS the voices from
  the live site and reverts it to device speech. Verify `ttsPremium.ts` +
  `public/tts/manifest.json` are present before any deploy.
- Any NEW UI that speaks (including the Battle feature) MUST call the shared
  `speak()`/`speakSlow()` helpers (which route through ttsPremium), never raw
  `speechSynthesis`, so it inherits the premium voices + fallback automatically.
